\# 🍿 Movie Suggest



A content-based movie recommendation system. Pick a movie and get 10 similar recommendations with posters and ratings.



\*\*Live Demo\*\*: https://movie-suggest-production-bdc5.up.railway.app



\## Features

\- 10 similar movie recommendations

\- Year filter

\- Movie posters and ratings from TMDB



\## Tech Stack

\- Streamlit, Python, Pandas, scikit-learn

\- TMDB API

\- Deployed on Railway



\## How to run locally

```bash

pip install -r requirements.txt

streamlit run app.py
